# MITRE ATT&CK Mapping — CloudTrail Tampering Detection

This lab detects attempts to disable or modify AWS CloudTrail logging using Elastic Security.

## ATT&CK Mapping

| Tactic | Technique | Event |
|--------|-----------|-------|
| Defense Evasion (TA0005) | Impair Defenses (T1562) | StopLogging |
| Defense Evasion (TA0005) | Impair Defenses (T1562) | StartLogging |
| Defense Evasion (TA0005) | Impair Defenses (T1562) | UpdateTrail |

## Why This Matters

Attackers often tamper with CloudTrail to hide their actions after gaining access to an AWS account. Detecting these events helps identify attempts to evade logging and monitoring.

## Detection Logic

```kql
data_stream.dataset:"aws.cloudtrail"
and event.action:("StopLogging" or "StartLogging" or "UpdateTrail")
```

## Lab Validation

The detection was tested by performing three actions in AWS:

- Disabled CloudTrail logging (`StopLogging`)
- Re-enabled logging (`StartLogging`)
- Modified trail configuration (`UpdateTrail`)

Elastic Security generated alerts for each tampering event.
