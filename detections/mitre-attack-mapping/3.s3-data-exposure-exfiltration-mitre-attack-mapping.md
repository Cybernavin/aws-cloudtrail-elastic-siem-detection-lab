# MITRE ATT&CK Mapping — S3 Data Exposure & Exfiltration Detection

This detection monitors suspicious access and modification of sensitive objects stored in an Amazon S3 bucket using AWS CloudTrail Data Events.

## ATT&CK Mapping

| ATT&CK Tactic             | Technique                                     | Why it applies                                                                                   |
| ------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Collection (TA0009)**   | **Data from Cloud Storage Object (T1530)**    | Detects `GetObject` events when files are accessed or downloaded from the monitored S3 bucket.   |
| **Exfiltration (TA0010)** | **Exfiltration to Cloud Storage (T1567.002)** | Detects `PutObject` events that may indicate data being uploaded or moved through cloud storage. |

## CloudTrail Events Monitored

| Event          | Description                             |
| -------------- | --------------------------------------- |
| `GetObject`    | File downloaded or accessed from S3.    |
| `PutObject`    | File uploaded or replaced in S3.        |
| `DeleteObject` | File deleted from the monitored bucket. |

## Detection Summary

* **Log Source:** AWS CloudTrail S3 Data Events
* **Platform:** AWS / Elastic Security
* **Severity:** High
* **Risk Score:** 75
